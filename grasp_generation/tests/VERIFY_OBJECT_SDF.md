# 物体SDF验证功能

## 功能说明

`--verify_object_sdf` 选项用于验证物体模型本身的SDF计算是否正确，与手部模型无关。

### 验证原理

1. 在物体bounding box内生成均匀的体素网格（默认32³个点）
2. 计算每个体素点到物体网格的SDF距离
3. **理论预期**：
   - **内部点**（在物体内部）：SDF > 0（红色）
   - **表面点**（在物体表面）：SDF ≈ 0（绿色）
   - **外部点**（在物体外部）：SDF < 0（蓝色）
4. 如果分布不合理，可能表示：
   - 物体网格质量有问题（非流形、有孔洞等）
   - SDF计算有误
   - 网格法向量方向不一致

### 判断标准

由于使用体素网格覆盖整个bbox，判断标准不同于表面采样点：

**合理的物体SDF分布**：
- ✅ 内部点数量合理（取决于物体体积占bbox的比例）
- ✅ 外部点数量合理（通常占大多数，因为bbox包含空白区域）
- ✅ 表面点数量较少（只有一薄层）
- ✅ 内部点全部SDF>0
- ✅ 外部点全部SDF<0
- ✅ 没有明显的符号错误（如物体内部出现大量负值）

**可能有问题**：
- ⚠️ 内部/外部点的符号分布混乱
- ⚠️ 表面点比例过高（>10%），可能网格分辨率太低
- ⚠️ SDF值的数量级不合理（过大或过小）

**明显有问题**：
- ❌ 内部出现大量负值点，或外部出现大量正值点
- ❌ SDF符号与空间位置明显不符
- ❌ SDF场不连续或有突变

## 常见问题

### Q1: 为什么有些外部点的SDF是正值（或内部点是负值）？

**A**: 这通常表示有问题：
1. **网格法向量不一致**：网格的法向量方向混乱
2. **非流形网格**：网格有边界、孔洞或自相交
3. **SDF计算错误**：TorchSDF库使用不当或有bug
4. **网格质量问题**：退化的三角形、重复顶点等

如果只有少量点（<1%）符号错误，可能是数值误差，可以接受。

### Q2: 表面点的比例应该是多少？

**A**: 取决于分辨率：
- **32³体素**：表面点约占2-5%
- **64³体素**：表面点约占1-3%（更精细）
- **16³体素**：表面点约占5-10%（较粗糙）

如果表面点比例异常高（>15%），可能是：
1. 体素分辨率太低
2. 网格表面不光滑，有很多突起
3. SDF阈值设置不合适（当前是±0.001）

### Q3: 什么情况下需要使用这个功能？

**A**: 以下情况建议使用：
1. 导入新的物体模型
2. 修改了物体网格处理流程
3. E_pen计算出现异常值
4. 怀疑物体网格有问题
5. 调试SDF相关代码

### Q4: 如果验证失败怎么办？

**A**: 如果发现符号分布混乱或不合理：
1. 检查物体网格文件是否正确加载
2. 检查网格是否是流形（manifold）
3. 检查网格是否有孔洞或自相交
4. 检查法向量方向是否一致
5. 尝试重新处理网格（manifold处理、修复、简化等）
6. 使用MeshLab等工具检查网格质量

### Q5: 内部和外部点的比例有什么意义？

**A**: 
- **比例取决于物体形状**：紧凑的物体（如球）内部点多，细长的物体内部点少
- **大致范围**：内部点通常占10%-40%，外部点占60%-90%
- **表面点最少**：通常只占2%-5%
- **如果内部点过多**（>60%）：可能bbox太紧，或物体很饱满
- **如果内部点过少**（<5%）：可能物体很薄或很空心

## 技术细节

### 实现原理

```python

bbox_min = object_vertices.min(dim=0)
bbox_max = object_vertices.max(dim=0)

# 2. 在bbox内生成均匀体素网格
x = np.linspace(bbox_min[0], bbox_max[0], resolution)
y = np.linspace(bbox_min[1], bbox_max[1], resolution)
z = np.linspace(bbox_min[2], bbox_max[2], resolution)
voxel_points = np.meshgrid(x, y, z)  # resolution³个点

# 3. 计算每个体素点到物体的SDF
distances, normals = object_model.cal_distance(voxel_points)

# 4. 验证SDF场的合理性
# 内部点应该>0, 外部点应该<0, 表面点应该≈0
```

### 为什么不显示手部？

验证物体SDF时不显示手部模型，因为：
1. 验证过程与手部无关
2. 避免视觉干扰
3. 专注于物体本身的质量

## 总结

`--verify_object_sdf` 是一个诊断工具，用于：
- ✅ 验证物体模型的SDF计算正确性
- ✅ 检查网格质量和法向量方向
- ✅ 可视化整个3D SDF场（内部/表面/外部）
- ✅ 调试物体相关问题
- ✅ 确保后续的penetration计算基础正确

**推荐工作流程**：
1. 首先使用 `--verify_object_sdf` 验证物体SDF场
2. 检查内部/外部/表面点的分布是否合理
3. 确认物体SDF正确后，再进行手部penetration分析
4. 这样可以排除物体本身的问题，专注于手部相关的问题

**与其他工具配合**：
- 使用 `--verify_object_sdf` 验证物体 ✅
- 使用默认模式验证E_pen计算 ✅
- 使用 `--use_voxel_grid` 分析手部穿透 ✅
